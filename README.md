## 📖 About The Project

**RupeeCalc Pro** is a modern, lightweight, and 100% mobile-responsive financial utility web application designed for Indian users. It allows anyone to instantly calculate their **Home/Car/Personal Loan EMIs**, **Mutual Fund SIP Returns**, and **GST Tax Splits (CGST + SGST)** in real-time without page reloads.

---

## ✨ Key Features

- 🏦 **Loan EMI Calculator:** Instant monthly EMI, total interest payable, and principal vs. interest visual ratio bar.
- 📈 **Mutual Fund SIP Calculator:** Calculate long-term wealth gain and total maturity value using compounding formulas.
- 🧾 **GST Calculator:** One-click GST inclusive calculation with automatic 50-50 CGST and SGST breakdown.
- ⚡ **Real-Time Sliders:** Smooth interactive range sliders synced with number inputs for instant results.
- 🛡️ **Smart AdBlock & DNS Guard:** Built-in detection for AdGuard DNS (`dns.adguard.com`) and browser adblockers.
- 🎁 **Click-to-Unlock Ad-Free Mode:** Interactive reward system that removes all ad containers cleanly once the user interacts with a highlighted sponsor slot.
- 📱 **100% Device Reflexive:** Works flawlessly on Mobile, Tablet, and Desktop screens.

## 🧮 Financial Formulas Used

1. **Loan EMI Formula:**
   $$EMI = \frac{P \times R \times (1+R)^N}{(1+R)^N - 1}$$
   *(Where $P$ = Principal, $R$ = Monthly Interest Rate, $N$ = Tenure in Months)*

2. **Mutual Fund SIP Formula:**
   $$M = P \times \left(\frac{(1 + i)^n - 1}{i}\right) \times (1 + i)$$
   *(Where $P$ = Monthly SIP, $i$ = Periodic Rate of Interest, $n$ = Total Months)*
